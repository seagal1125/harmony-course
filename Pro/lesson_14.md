# 第 14 章：終止式武道館 (Bonus) —— 10 種讓音樂完美落地的姿勢

> [!NOTE]
> **本課目標**：終止式 (Cadence) 是音樂的標點符號。沒有它們，音樂就只是一堆停不下來的廢話。這一章我們將前面學過的散招，整理成一套完整的「降落指南」。

---

## 第一類：古典四大天王 (The Big Four)

這四種終止式是所有西方音樂的地基。

### 1. 正格終止 (Perfect Authentic Cadence, PAC)
*   **公式**：**V7 -> I** (G7 -> C)
*   **符號**：**句號 (。)**
*   **聽感**：最強烈、最完整、最肯定的結束。回家了，關門，睡覺。
*   **實例**：幾乎所有古典交響曲的最後三秒鐘。

### 2. 變格終止 (Plagal Cadence)
*   **公式**：**IV -> I** (F -> C)
*   **符號**：**阿們 (Amen)**
*   **聽感**：溫柔、神聖、像是在說「就這樣吧」。它缺乏 V7 的強烈導音推力，所以感覺比較平靜。
*   **實例**：教堂聖歌的最後一句「阿～們」。
*   **實例**：**披頭四《Yesterday》**。唱完最後一句時，和弦就是 IV -> I。

### 3. 半終止 (Half Cadence, HC)
*   **公式**：**停在 V** (C -> ... -> G)
*   **符號**：**問號 (?) 或 逗號 (，)**
*   **聽感**：話沒講完，懸在半空中，用來引入下一段。
*   **實例**：**《Happy Birthday》**。
    *   "Happy birthday to **you**..." (停在 V)。
    *   你一定要接著唱下一句，不然會很難受。

### 4. 阻礙/假終止 (Deceptive Cadence, DC)
*   **公式**：**V -> vi** (G -> Am)
*   **符號**：**驚嘆號 (!)**
*   **聽感**：聽眾預期要回 I (家)，結果你帶他去旁邊的 vi (鄰居家)。驚喜、錯愕、延長劇情。
*   **實例**：**OneRepublic - 《Apologize》**。

---

## 第二類：爵士與流行特調 (Jazz & Pop Specials)

### 5. 後門終止 (Backdoor Cadence)
*   **公式**：**iv7 -> bVII7 -> I** (Fm7 -> Bb7 -> C)
*   **聽感**：這被稱為「爵士樂的變格終止」。
    *   它不像 V7 那麼強勢，而是繞這「後門」溜進主和弦。
    *   Bb7 裡面的 **Ab** 音平滑地下行解決到 **G**。
*   **實例**：**Stevie Wonder** 的歌大量使用這種黑人音樂特有的轉折。

### 6. 小下屬終止 (Minor Plagal)
*   **公式**：**IV -> iv -> I** (F -> Fm -> C)
*   **符號**：**嘆息 (~)**
*   **聽感**：我們在第 12 章提過。那種瞬間的憂鬱與釋懷。
*   **實例**：**Green Day - 《Wake Me Up When September Ends》**。

---

## 第三類：史詩與異國情調 (Epic & Exotic)

### 7. 安達魯西亞終止 (Andalusian Cadence)
*   **公式**：**i -> bVII -> bVI -> V** (Am -> G -> F -> E)
*   **聽感**：弗朗明哥 (Flamenco)、鬥牛士、激情。
*   **實例**：**Ray Charles - 《Hit the Road Jack》**。

### 8. 瑪利歐終止 (Mario Cadence)
*   **公式**：**bVI -> bVII -> I** (Ab -> Bb -> C)
*   **聽感**：英雄凱旋、升級、壯闊。
*   **實例**：**任天堂所有遊戲的通關畫面**。它有一種「往上爬樓梯」最後登頂的感覺。

### 9. 皮卡地終止 (Picardy Third)
*   **公式**：**小調歌 -> 大調 I 結束** (Am... -> **A Major**)
*   **符號**：**陽光 (☀)**
*   **聽感**：救贖。烏雲散去。

### 10. 三全音代理終止 (Tritone Sub)
*   **公式**：**bII7 -> I** (Db7 -> C)
*   **聽感**：絲般滑順。像貓一樣輕輕落地。

## 🎹 動手實作：終止式馬拉松

我們用 C 大調來跑完這 10 種姿勢。

### 流程：
1.  **PAC**: G7 -> C
2.  **Plagal**: F -> C
3.  **Half**: C -> F -> **G (停!)**
4.  **Deceptive**: G -> **Am (嚇一跳)**
5.  **Minor Plagal**: F -> **Fm** -> C
6.  **Mario**: Ab -> Bb -> C (用力!)
7.  **Backdoor**: Fm7 -> Bb7 -> C (Jazz手級)

**練習心法**：
不只是彈出來，要試著在彈之前，**先在腦海裡預想那個聲音**。這才是聽力訓練的終極目標。
