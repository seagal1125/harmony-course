# 第 12 章：調式互換 —— 偷來的顏色 (Modal Interchange)

> [!NOTE]
> **本課目標**：副屬和弦是去「別人家」借引力，調式互換是把「平行世界」的顏色拿來用。最常見的就是：在大調歌曲裡，借用小調的和弦。

---

## 12.1 平行宇宙：同主音大小調

*   **C Major** (現實世界)：C, Dm, Em, F, G, Am, Bdim。
*   **C Minor** (平行世界)：Cm, Ddim, Eb, Fm, Gm, Ab, Bb。

**調式互換 (Modal Interchange)** 就是：我在寫 C Major 的歌，但我突然拿了一個 C Minor 裡面的和弦來用。

---

## 12.2 最美的借用：小下屬和弦 (iv)

在大調裡，四級通常是 **F (IV)**。
但如果我們借用小調的四級 **Fm (iv)**...

*   **進行**：**C -> F -> Fm -> C**。
*   **原理**：
    *   **F** (IV): F - **A** - C
    *   **Fm** (iv): F - **Ab** - C
    *   **C** (I): E - **G** - C
*   **關鍵線條**：A (La) -> Ab (降La) -> G (Sol)。
*   **聽感**：那個 **Ab** 音是一個「痛點」。它帶來一種懷舊、遺憾、回憶湧上心頭的感覺。

### 實例賞析
1.  **Bruno Mars - 《When I Was Your Man》**
    *   副歌最後一句：Take you to every **party** cause all you wanted to do was **dance**.
    *   那個 "dance" 用了 **Fm**。那個遺憾感瞬間爆棚。
2.  **《Cinema Paradiso》(新天堂樂園)**
    *   愛的主題曲中，大量使用了這種 IV -> iv 的進行，營造出電影般的歲月感。
3.  **Radiohead - 《Creep》**
    *   再一次提到它。C -> E -> F -> **Fm**。它把副屬和弦(E)和小下屬和弦(Fm)都用上了，難怪這麼憂鬱。

---

## 12.3 英雄的結局：皮卡地終止 (Picardy Third)

這是反過來：**在小調歌曲的最後，突然用大調結束。**

*   **進行**：Am -> Dm -> E7 -> **A Major!**
*   **聽感**：烏雲密佈了一整首歌，最後一刻陽光穿透雲層。象徵救贖、昇華、希望。
*   **實例**：**巴哈的大量賦格曲**。
*   **實例**：**迪士尼《Frozen》 - 《Let It Go》**。
    *   雖然它是大調歌，但很多段落是在小調徘徊，最後才爆發出大調的光輝。

---

## 12.4 瑪利歐的無敵星：bVI 和 bVII

借用小調的 **Ab (bVI)** 和 **Bb (bVII)**。

*   **進行**：**C -> Bb -> Ab -> G**。
*   **聽感**：這是一種很「壯闊」的下行。這兩個和弦本來不屬於 C 大調，用起來有一種「史詩冒險」的感覺。
*   **實例**：**超級瑪利歐 (Super Mario) 通關音樂**。
    *   那個旗子降下來的時候，聽到的就是 bVI -> bVII -> I 的變體。它給人一種「凱旋歸來」的勝利感。

---

## 🎹 動手實作：調色盤大師

### 任務一：把「開心」變成「遺憾」
1.  彈一個最簡單的結束：**F -> G -> C**。 (IV -> V -> I)。這很正常。
2.  現在加入「遺憾」：**F -> Fm -> C**。
    *   F (F-A-C)
    *   Fm (F-Ab-C) <- 重點在那個 Ab！
    *   C (E-G-C)
3.  試著在任何一首大調歌曲的結尾偷用這招，看看會不會讓聽眾掉眼淚。

### 任務二：瑪利歐凱旋
1.  我們要用 **bVI - bVII - I**。
2.  在 C 大調裡：
    *   彈 **Ab Major** (Ab-C-Eb)。
    *   彈 **Bb Major** (Bb-D-F)。
    *   彈 **C Major** (C-E-G)。
3.  用力彈！這叫做 **"Mario Cadence"**。是不是覺得自己剛打贏了庫巴？
