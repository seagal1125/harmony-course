第 15 章：懸浮與釋放 (Bonus) —— 掛留和弦 (sus) 的全方位解析

NOTE 本課目標：學會「延遲滿足」。掛留和弦 (Suspended Chord, sus) 的本質就是：我現在不告訴你我是開心 (Major) 還是悲傷 (Minor)，我要讓你等一下。

15.1 物理原理：為什麼要「掛」起來？

正常的三和弦有三層樓：1樓 (根音)、3樓 (三音)、5樓 (五音)。 三音 (3rd) 最重要，因為它決定了這棟樓是亮的 (Major) 還是暗的 (Minor)。

掛留 (Suspension) 就是把應該在 3 樓的人，先掛在 4 樓 (sus4) 或 2 樓 (sus2)。

  • Sus4 (1-4-5)：第 4 音 (Fa) 跟第 3 音 (Mi) 只差半音。地心引力會把它往下拉。
  • Sus2 (1-2-5)：第 2 音 (Re) 跟第 1 音 (Do) 雖然也是相鄰，但它有一種更寬闊、想往上飄到 3 的感覺。

15.2 四大流派的用法

1. 古典派：嚴格的嘆息 (4 -> 3 Resolution)

這是最傳統的用法。所有的 sus4 最終必須解決回到 3。

  • 公式：Vsus4 -> V -> I
    • (G-C-D) -> (G-B-D) -> (C-E-G)
  • 聽感：就像一個人深吸一口氣，憋住 (sus4)，然後嘆氣 (3)，最後放鬆 (I)。
  • 場景：教堂音樂、巴洛克音樂、或是像惠妮休斯頓《I Will Always Love You》那種大歌的結尾，那個長長的 sus4 解決瞬間。

2. 流行搖滾派：吉他手的「刷扣」神技

在流行歌裡，吉他手很喜歡在同一個和弦裡不斷變換，讓伴奏聽起來有動態。

  • 動作：D -> Dsus4 -> D -> Dsus2 -> D
    • 手指動來動去，但和弦一直釘在 D 上。
  • 聽感：流動、豐富、像是水波紋。它沒有強烈的解決壓力，純粹是為了好聽。
  • 實例：
    • Queen - 《Crazy Little Thing Called Love》：前奏那把吉他就是不斷在 D 和弦上玩 sus4。
    • Bryan Adams - 《Summer of '69》：典型的搖滾刷法。

3. 現代配樂派：永不落地的太空人 (Non-resolving sus)

這是 Hans Zimmer 或 Coldplay 很愛的招數。sus 和弦根本不解決。

  • 公式：Fsus2 -> Csus2 -> Gsus4...
  • 聽感：因為拿掉了 3 音（沒有明確的悲喜），音樂變得很中性、廣闊、充滿空氣感。
  • 場景：
    • 電影《星際效應》(Interstellar) 裡的浩瀚宇宙。
    • Coldplay 的前奏，營造那種大巨蛋演唱會的氛圍。
    • 這種用法會讓聽眾覺得「我們正在漂浮」，而不是「我們到家了」。

4. 爵士派：Vsus7 的雙重身份

爵士樂手把 G7sus4 看作是一個「混合體」。 G7sus4 = F/G (右手彈 F 大三和弦，左手彈 G)。

  • 公式：Dm7/G 或 F/G
  • 功能：它同時具有下屬 (F/Dm) 和屬 (G) 的功能。
  • 用法：在 ii-V-I 進行中，有時會直接用 G7sus4 取代掉整個 Dm7 -> G7 的過程，讓聲音更平滑、更現代。
  • 實例：Herbie Hancock - 《Maiden Voyage》。整首曲子幾乎都是由不會解決的 sus 和弦堆疊而成，創造出像海浪一樣的漂浮感。

🎹 動手實作：懸浮體驗

任務一：古典的嘆息

  1. 左手：彈低音 G。
  2. 右手：彈 C 和 D (Fa 和 Sol)。這是 Gsus4 的核心衝突。
  3. 聽：感受那個 C (Fa) 和 G (Sol) 撞在一起的緊張感。
  4. 解決：右手把 C (Fa) 往下移動半格變成 B (Si)。
  5. 釋放：啊... 舒服了。這就是 4-3 Suspension。

任務二：搖滾刷扣 (D Major)

  1. 右手：彈 D 和弦 (D-F#-A)。
  2. 變形：
    • 小指按下去 G (變成 D-G-A) -> sus4。
    • 放開小指回到 F# -> Major。
    • 食指放開 F# 變成 E (D-E-A) -> sus2。
  3. 節奏：試著用像是 下-下上-上下-下上 的掃弦節奏，隨意切換這三種狀態。恭喜你，你會彈摇滾吉他了（在鋼琴上）。

任務三：太空漫遊

  1. 不要彈任何 3 音 (不要彈 E, B, A...)。
  2. 只彈 1, 2, 5 (Do, Re, Sol)。例如 Csus2 (C-D-G)。
  3. 隨便亂跑：Csus2 -> Fsus2 -> Gsus2。
  4. 是不是覺得自己也是 Hans Zimmer 了？這種聲音非常適合當作背景音樂 (Ambient Music)。
