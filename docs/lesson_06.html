第 6 章：和聲動力學 —— T-S-D 系統 (Harmonic Dynamics)

NOTE 本課目標：為什麼音樂會有「起承轉合」？因為和弦有功能。本章將揭示驅動所有音樂前進的引擎：Tonic (主)、Subdominant (下屬)、Dominant (屬) 系統。

6.1 音樂的三大角色 (T-S-D)

如果把音樂比喻成一部電影，和弦就是裡面的角色。不管劇本怎麼變（調性怎麼變），角色的功能通常只有三種：

1. 主功能 (Tonic, T) —— 家 (Home)

  • 代表和弦：I (C), vi (Am), iii (Em)。
  • 特徵：穩定、放鬆、結局。
  • 感覺：故事的起點，也是終點。腳踏實地的感覺。

2. 下屬功能 (Subdominant, S) —— 旅程 (Journey)

  • 代表和弦：IV (F), ii (Dm)。
  • 特徵：離開家、變化、流動。
  • 感覺：故事開始發展了。「出發去冒險」、「場景轉換」。它有一種離心力，把音樂帶離主音。

3. 屬功能 (Dominant, D) —— 懸念 (Climax)

  • 代表和弦：V (G, G7), vii° (Bdim)。
  • 特徵：緊張、衝突、不穩定。
  • 感覺：故事的高潮。「壞人出現」、「命懸一線」。它有一種強大的向心力，迫切需要解決回主音。

TIP 動力公式：大多數音樂的劇本都是：家 (T) -> 出發 (S) -> 衝突 (D) -> 回家 (T)。

6.2 解決 (Resolution)：為什麼 V7 一定要回 I？

這就是前面章節提到的「物理學」與「心理學」的總驗收。 以 C 大調為例，G7 (V7) 接 C (I) 是最強的解決。為什麼？

  1. 導音的磁力：G7 裡面的 B (Si)，距離主音 C (Do) 只有半音。它像磁鐵一樣被吸上去。
  2. 下屬音的重力：G7 裡面的 F (Fa)，距離 E (Mi) 也只有半音。不協和音傾向於「解決」到最近的協和音。

  3. 三全音的釋放：B 和 F 之間是恐怖的三全音。當 B 往上跑、F 往下跑，三全音就被「化解」成了穩定的 C-E (大三度)。

  4. 實例：古典終止式 (Authentic Cadence)。

    • 聽聽莫札特或海頓的交響曲結尾，總是 Sol-Sol-Sol-Do! 那就是 V-I 的勝利宣言。

6.3 流行樂的四和弦：1-5-6-4

你一定聽過這個進行，因為它寫了幾千首流行歌。 I - V - vi - IV (C - G - Am - F)。

讓我們用 T-S-D 分析它為什麼紅： 1. I (C): 家 (T)。開場。 2. V (G): 屬 (D)。才剛開始就給一個半終止，讓人覺得「還有話要說」。 3. vi (Am): 更是家 (T)，但是是悲傷的家（假終止）。從明亮轉為糾結。 4. IV (F): 下屬 (S)。開放的結尾，這是一個「懸念」。因為停在 IV，所以可以無限循環回到 I，也可以接到 V。

  • 實例：The Beatles - 《Let It Be》。
  • 實例：Jason Mraz - 《I'm Yours》。
  • 實例：五月天 - 《突然好想你》 (主歌)。

這組進行之所以無敵，是因為它一直在 T-D-T-S 之間晃動，既有張力又不會太刺激，非常適合唱KTV。

6.4 另類選擇：Radiohead 的 Creep (IV -> iv)

有時候我們想要更高級的感覺。 Radiohead - 《Creep》：G - B - C -Cm。

  • 原本應該是 C (IV) 回到 G (I)。
  • 但它變成 C (IV) -> Cm (iv)。
  • 原理：這叫做小下屬和弦 (Minor Plagal Cadence)。Cm 裡面的 Eb 音，會半音下行滑到 D (G的和弦音)。
  • 聽感：那種「心碎」、「無力感」、「這輩子就這樣了」的頹廢美，全靠這個 IV -> iv 的變化。

🎹 動手實作：指揮家的魔杖

任務一：感受 V7 的引力

  1. 右手：彈 G - B - D - F (G7)。這是一個充滿張力的和弦。
  2. 停住：聽聽那個聲音，是不是覺得「很不舒服」、「話沒講完」？
  3. 解決：
    • B (Si) -> C (Do)
    • F (Fa) -> E (Mi)
    • 右手彈 C - E (代表 C 和弦)。
  4. 瞬間：感受到那個「啊... 舒服了」的釋放感了嗎？這就是解決。

任務二：彈奏流行金曲 1-5-6-4

  1. 左手根音，右手三和弦。
  2. C (1) -> G (5) -> Am (6) -> F (4)。
  3. 試著哼唱隨便一首你喜歡的歌，你會驚訝地發現有很大概率能套進去。例如《Frozen》的 Let It Be... 啊不對，是 Let It Go (Let It Go 其實是 iv-I-V-vi 變體，但邏輯類似)。
