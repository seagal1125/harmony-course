第六章：和聲動力學 —— 解決、磁力與 Sus 和弦

[!NOTE]
學習目標：為什麼音樂聽起來會「還沒講完」？為什麼 Sus 和弦聽起來這麼心癢？本課將帶你掌握音樂中最核心的推動力：解決 (Resolution)。

6.1 什麼是「解決」？ (音樂的心理引力)

在音樂理論中，解決是指從「緊張/不穩定」的和聲，移動到「放鬆/穩定」的和聲。

🧲 半音的磁力：導音 (Leading Tone)

上一章我們提過導音（7級）。在 C 大調中，那是 B。
* 物理性質：B 與 C 只差一個半音，距離極近。
* 心理感受：當你聽到 B，大腦會自動產生一種「磁力」，渴望聽到它滑上去變成 C。這種渴求就是「解決」的動力來源。

6.2 Sus 和弦：極致的懸念 (Suspense)

您提到的 Sus (Suspended，掛留和弦) 正是「解決」章節的明星。

🏗️ 構造解析：Sus4 與 Sus2

  1. Sus4 (掛留四度)：如 Csus4 (C-F-G)。

    • 視覺化描述：想像你原本雙腳踩地 (C)，但現在有人把你的右腳抬起來掛在半空中 (F)。
    • 解決：F (4度) 渴望滑下來回到 E (3度)。

  2. Sus2 (掛留二度)：如 Csus2 (C-D-G)。

    • 視覺化描述：想像你原本站得很穩，但有人推了你一把，讓你踮起腳尖 (D)。
    • 解決：D (2度) 渴望滑上去回到 E (3度)，或者滑下來回到 C。

6.3 實例驅動：從 Hans Zimmer 到《哈利波特》

🚀 範例：史詩電影配樂中的 Sus

當 Hans Zimmer 想表達一種「命懸一線」或「正在思考」的氛圍時，他不彈大調也不彈小調，而是一直彈 Sus2 或 Sus4。
* Sus2 的空靈感：您喜歡《星際效應》那種現代感，Sus2 的和聲比 Sus4 更「透明」，常用在極簡主義的旋律中。

6.4 🎹 在鍵盤上彈彈看！

任務一：體驗 Sus4 的「心癢」與「釋放」

  1. 右手按住 C - F - G (Csus4)。
  2. 閉上眼感受那種不平衡感。
  3. 把食指的 F 放掉，移到 E (變成 C Major)。
  4. 聽聽看，那種「終於回到家」的感覺。

任務二：為《星際效應》加點懸念 (Sus2 版)

  1. 左手彈低音 A1 - A2。
  2. 右手彈 A - B - E (Asus2)。
  3. 觀察那個 B 帶來的空曠感。
  4. 緩慢地將 B 推向 C (Am)。這就是一種微小的、有現代感的解決。
