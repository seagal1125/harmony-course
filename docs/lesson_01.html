第 1 章：聲音的物理學 —— 泛音列與和聲的起源 (The Physics of Sound)

NOTE 本課目標：理解為什麼有些音在一起好聽（協和），有些音在一起會打架（不協和）。這一切的答案，都藏在自然界的物理規律——「泛音列」之中。

1.1 泛音列：隱藏在聲音裡的彩虹

當你彈下鋼琴上的一個 C (Do) 鍵時，你聽到的不只是一個音，而是一整串像彩虹一樣疊加出來的泛音 (Overtones)。這就是為什麼同一個音，鋼琴、小提琴和長笛聽起來不一樣（音色不同），因為它們泛音的音量比例不同。

🎻 泛音列的自然順序

想像一條振動的琴弦，它同時以不同的比例分割在振動：

  1. 基音 (Fundamental)：整條弦振動。
    • 頻率：f (假設是 C2)
    • 聽感：這是我們聽到的主要音高。
  2. 第二泛音 (Octave)：弦切一半振動。
    • 頻率：2f (C3, 高八度)
    • 關係：純八度。這是最完美的融合，聽起來像同一個音。
  3. 第三泛音 (Perfect 5th)：弦切成三份。
    • 頻率：3f (G3, 再高純五度)
    • 關係：純五度。這是除了八度以外，最協和的音程。這就是為什麼「5度」在音樂中這麼重要，它是大自然給我們的第一個禮物。
  4. 第四泛音 (Octave)：弦切成四份。
    • 頻率：4f (C4, 再高純四度回到本音)
  5. 第五泛音 (Major 3rd)：弦切成五份。
    • 頻率：5f (E4, 再高大三度)
    • 關係：大三度。加上這個音，我們就得到了 C Major Triad (C-E-G)。大三和弦之所以好聽，是因為它是泛音列最前端的自然產物。

TIP 視覺化想像： 泛音列就像金字塔。底部最寬（基音），往上越來越密。 * 底層：C (基音) * 第二層：C (八度，穩固) * 第三層：G (五度，支撐) * 第四層：E (三度，色彩) * 再往上：Bb (小七度)... 開始出現不協和音。

1.2 協和與不協和：物理學的解釋

為什麼 C 和 G 聽起來很和諧，但 C 和 C# 聽起來很刺耳？

  • 協和 (Consonance)：頻率比例簡單 (如 2:1, 3:2)。
    • 聲波波形能夠有規律地重疊，大腦處理起來很輕鬆，感覺「放鬆」、「穩定」。
    • 例如：純五度 (Power Chord)，常用於搖滾樂開場，如 Deep Purple 的《Smoke on the Water》，乾淨有力。
  • 不協和 (Dissonance)：頻率比例複雜 (如 16:15)。
    • 聲波會互相干擾，產生「拍頻 (Beats)」，聽起來嗡嗡作響。大腦會感覺「緊張」、「需要解決」。
    • 例如：小二度 (Jaws Theme)，電影《大白鯊》的主題曲，那個 E-F 的來回切換，就是利用小二度的極度不協和來製造恐懼感。

1.3 實例賞析：不同音程的情緒

讓我們離開理論，聽聽不同音程在名曲中的應用：

1. 純五度 (Perfect 5th) —— 英雄與空曠

  • 聽感：穩定、空靈、壯闊。
  • 範例：電影《星際大戰》主題曲 (Star Wars Theme)。
    • 開頭的小號：Do - Sol (1 - 5)。
    • 那個向上的跳躍，就充滿了英雄出發的自信感。
  • 範例：電影《2001太空漫遊》開頭 (Also sprach Zarathustra)。
    • C - G - C。用最純粹的五度和八度，表現宇宙的浩瀚。

2. 大三度 vs 小三度 (Major vs Minor 3rd) —— 光明與悲傷

  • 大三度 (1 - 3)：明亮、快樂。
    • 範例：《布拉姆斯搖籃曲》(Brahms' Lullaby)。開頭就是大三度，溫暖安詳。
    • 範例：《The Saints Go Marching In》 (Oh when the saints...)，開頭 Do-Mi-Fa-Sol，大三度帶來正向的能量。
  • 小三度 (1 - b3)：悲傷、嚴肅。
    • 範例：《綠袖子》(Greensleeves)。開頭的高音 Sol 下行到 Mi (小調的 b3)，瞬間建立憂傷的基調。
    • 範例：貝多芬《命運交響曲》 (Da-Da-Da-Dunn...)。那個著名動機包含大三度下行，但在C小調背景下，聽起來充滿命運的敲擊感。

3. 三全音 (Tritone) —— 魔鬼的音程

  • 聽感：極度不穩定、懸疑、危險。它剛好卡在純四度和純五度中間 (增四/減五度)。
  • 範例：動畫《辛普森家庭》(The Simpsons) 片頭曲。
    • "The Simp-sons" 這個旋律就是三全音 (C - F#)。聽起來是不是有一種古怪、滑稽又有點扭曲的感覺？
  • 範例：Saint-Saëns《骷髏之舞》(Danse Macabre)。
    • 小提琴獨奏用了三全音來模仿骨頭撞擊的聲音。

🎹 動手實作：在琴鍵上實驗物理學

請打開您的鋼琴或鍵盤 App，跟著做以下實驗，用耳朵驗證物理學。

任務一：體驗泛音列 (如果使用聲學鋼琴效果最好)

  1. 無聲按下 C3 (中央 C 下方八度) 並保持按住 (不要讓它發出聲音，只是為了抬起制音器)。
  2. 用另一隻手用力短促地彈一下 C2 (再低八度)，然後馬上放開 C2。
  3. 聆聽：你應該會聽到 C3 在隱隱作響！這就是共振。
  4. 進階：按住 G3 (五度音) 無聲，用力彈 C2。你會聽到 G3 也在響！因為 G3 是 C2 的第三泛音。

任務二：情緒調色盤

  1. 左手：彈低音 C (作為根基)。
  2. 右手：依次彈出以下音符，感受情緒變化：
    • 彈 G (五度)：是不是覺得很空、很穩？像是在山頂看風景。
    • 彈 E (大三度)：是不是突然有陽光照進來的感覺？
    • 彈 Eb (小三度)：是不是突然陰天了，有點憂鬱？
    • 彈 F# (三全音)：是不是覺得哪裡怪怪的，很想趕快把手移開？

這就是和聲學的本質：我們不是在背公式，而是在學習如何操控這些物理與心理的反應。
