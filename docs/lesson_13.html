第 13 章：進階門檻 —— 那些奇怪的一瞬間 (Introduction to Advanced Harmony)

NOTE 本課目標：如果你已經掌握了前面所有內容，恭喜你，你已經是個和聲高手了。最後這一章，我們要稍微窺探一下「大師級」的領域。這裡只有三個概念，但每一個都是通往新世界的鑰匙。

13.1 三全音代理 (Tritone Substitution) —— 蟲洞旅行

爵士樂手最愛的招數。 原理：G7 可以被 Db7 取代。為什麼？

  1. G7: G - B - F (三全音)。
  2. Db7: Db - F - Cb(B) (也是三全音！)。

  3. 因為它們共享同一個「三全音引擎」(B-F)，所以它們可以互換。解決到 C 的動力是一樣的。

  4. 效果：根音從 G -> C (跳五度)，變成了 Db -> C (半音下行)。

  5. 聽感：更平滑、更絲綢般、更爵士。像是「不想太用力解決」的優雅。

13.2 拿坡裡六和弦 (Neapolitan 6th) —— 義大利的嘆息

這是一個古典樂非常戲劇化的和弦：bII (降二級大三和弦)。 在 C 小調裡，它是 Db Major。

  • 用法：通常用來接 V (G7)。 Db -> G7 -> Cm。
  • 聽感：極度的悲劇性、戲劇性、歌劇感。
  • 實例：貝多芬《月光奏鳴曲》(Moonlight Sonata)。
    • 第一樂章開頭不久，那個讓人心頭一緊的和弦，就是拿坡裡六和弦。

13.3 減七和弦 (Diminished 7th) —— 萬能任意門

Cdim7 (C-Eb-Gb-Bbb)。 這是一個 完全對稱 的和弦。每一個音之間都是小三度。

  • 魔法：因為它是對稱的，所以 Cdim7 = Ebdim7 = Gbdim7 = Adim7。它們依然是同一組音！
  • 功能：你可以用它瞬間轉到 4 個不同的調！
    • 它是通往不同平行宇宙的樞紐。在電影配樂中，當主角突然穿越時空，或者劇情急轉直下時，通常伴隨著減七和弦。

這是本課程最後一個練習。我們要用一組進行，串聯這 13 章的精華。

終極進行 (Grand Finale)

試著在鍵盤上彈出這組進行，並說出每一個和弦的功能：

  1. Cmaj7 (家，I)
  2. A7 (副屬和弦，V7/ii) -> "我要去 Dm 了"
  3. Dm7 (下屬功能，ii)
  4. Fm (調式互換，iv) -> "一點點遺憾"
  5. Db7 (三全音代理，subV7) -> "平滑的半音下滑"
  6. Cmaj7 (完美的家)

如果你能理解這六個和弦為什麼這樣接，並且能彈出來感受它的美......

恭喜你！你已經聽見了音樂的幾何學。 現在，去創作屬於你自己的 Passacaglia 吧！
