第 11 章：副屬和弦 —— 借來的引力 (Secondary Dominants)

NOTE 本課目標：如果你覺得你的音樂一直在本調裡打轉很無聊，你需要一點「外遇」... 啊不是，是「離調」。副屬和弦讓你暫時去別的調旅行一下。

11.1 原理：我是誰的第五度？

在 C 大調裡，只有 G7 是屬和弦。因為它想回 C。 但如果我們想去 Am 呢？ Am 的「專屬磁鐵」是 E7 (因為 E 是 A 的第五度)。 雖然 E7 不在 C 大調裡（有 G#），但我們可以借用它。

這個 E7 就叫做 V7/vi (讀作：five-seven of six)。意思它是「六級和弦的屬七和弦」。

11.2 常見的「借用」手法

1. V7/V —— 推向屬和弦 (D7 -> G7)

  • 目標：我們要去 G (屬和弦)。
  • 工具：用 D7 (G 的五度)。
  • 進行：C -> D7 -> G7 -> C。
  • 聽感：D7 裡面的 F# 會強烈推向 G。這讓 G 的出現變得非常隆重。
  • 範例：CeeLo Green - 《Forget You》。
    • C - D7 - F - C。
    • 那個 D7 聽起來特別亮、特別復古。

2. V7/vi —— 悲傷的催化劑 (E7 -> Am)

  • 目標：要去 Am。
  • 工具：用 E7。
  • 進行：C -> E7 -> Am。
  • 聽感：這是流行歌最愛用的招數。E7 的 G# 音撕裂了原本平靜的 C 大調，帶來一種心痛的糾結感。
  • 範例：Radiohead - 《Creep》。
    • 雖然它主要是用小四級，但類似的張力在很多以 E7 接 Am 的歌曲中都有。
  • 範例：周杰倫 - 《安靜》。
    • 副歌前段常常用這種三級大和弦 (III7, 其實就是 V7/vi) 來接六級。

3. V7/ii —— 爵士的起手式 (A7 -> Dm)

  • 進行：C -> A7 -> Dm -> G7 -> C。
  • 分析：這其實就是一個連續的五度推動鏈 (A->D->G->C)。
  • 範例：《莫斯科郊外的晚上》 或很多老式爵士樂。

11.3 實例賞析：披頭四的神來之筆

The Beatles - 《Yesterday》 開頭：F -> Em7 -> A7 -> Dm... (原曲是 F 大調，這裡用 C 大調相對關係講比較好懂：C -> Bm7 -> E7 -> Am)

  • 那個 E7 (A7) 的出現，瞬間把這首歌從普通的民謠提升到了藝術層次。它提供了一種「宿命般」的拉扯力。

🎹 動手實作：調味實驗

任務一：把兒歌變高級

我們來改造《兩隻老虎》。 1. 原版：C - Dm - G - C。 (兩隻老虎... 跑得快...) 2. 加料版： * 在去 Dm 之前，先加一個 A7。 * C -> A7 -> Dm -> G -> C。 * 聽聽看：那個 A7 出現時，是不是覺得老虎突然戴上了墨鏡，變成了爵士老虎？

任務二：感受 E7 的心痛

  1. 左手彈 C -> G -> Am -> F (著名的1564)。聽起來很芭樂。
  2. 現在把第二個和弦 G 改成 E7。
  3. C -> E7 -> Am -> F。
  4. 聽聽看：哇！是不是突然變得很像陳奕迅或林俊傑的歌？那個 E7 -> Am 的情緒張力非常強大，這就是副屬和弦的魅力。
