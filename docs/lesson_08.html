第 8 章：模進的力量 —— 複製貼上的藝術 (The Power of Sequences)

NOTE 本課目標：為什麼有些旋律聽一遍就忘不掉？秘密在於「模進」(Sequence)。這是一種把音樂片段像積木一樣「複製、平移、貼上」的技巧。我們將重點學習最強大的 五度圈模進。

8.1 什麼是模進 (Sequence)？

模進就是：做一件事情，然後換個高度再做一次。

  • 動機 (Motif)：Do-Re-Mi (1-2-3)。
  • 模進：
    • 上移二度：Re-Mi-Fa (2-3-4)。
    • 再上移二度：Mi-Fa-Sol (3-4-5)。
  • 效果：既有「重複感」(好記)，又有「新鮮感」(音高變了)。這是洗腦神曲的必備條件。

8.2 五度圈模進 (Circle of Fifths Sequence)

這是和聲學中的核武器。還記得五度圈的「逆時針」運動嗎？如果我們連續走好幾步，就會形成一條強大的能量鏈。

公式：vi -> ii -> V -> I -> IV... (以 C 大調為例：Am -> Dm -> G -> C -> F...)

為什麼它這麼強？

  1. 多米諾骨牌效應：每一個和弦都是下一個和弦的「屬」(Dominant) 關係（或類屬關係）。
    • Am 是 Dm 的上行五度。
    • G 是 C 的上行五度。
  2. 聽感：就像大隊接力，棒子一棒接一棒傳下去，完全停不下來。

實例賞析

  1. 《I Will Survive》 - Gloria Gaynor

    • 這是迪斯可 (Disco) 的國歌。
    • 和弦：Am -> Dm -> G -> C -> F -> Bm7b5 -> E7 -> Am。
    • 發現了嗎？這就是一個完整的小調五度圈模進！它繞了幾乎一整圈，最後用 E7 接回 Am。那種「我會活下去」的堅定力量，就是來自這種連鎖反應。

  2. 《Fly Me to the Moon》

    • 前面提過，也是標準的五度圈模進。爵士樂最愛這招。

  3. 久石讓 - 《魔女宅急便》 (風之丘)

    • 日本動漫音樂非常喜歡用五度圈模進來製造「流動感」和「異世界感」。

8.3 另一種王者：下行四度模進 (Pachelbel's Canon)

雖然不是五度圈，但這個模進統治了流行樂壇 40 年。 卡農進行：I -> V -> vi -> iii -> IV -> I -> IV -> V (C -> G -> Am -> Em -> F -> C -> F -> G)

  • 邏輯：它不是「跳五度」，而是 「下行音階」 的變體。
    • 低音線：Do - Sol - La - Mi - Fa - Do...
    • 這聽起來像是一個緩慢的下樓梯過程。
  • 實例：
    • Maroon 5 - 《Memories》 (根本就是直接致敬卡農)。
    • 王力宏 - 《改變自己》。
    • 畢業歌《朋友》。
    • 韓國多數抒情歌。

這組進行給人的是「溫暖」、「懷舊」、「平穩」的感覺，跟五度圈那種「動力十足」的感覺不同。

🎹 動手實作：模進大師

任務一：彈奏《I Will Survive》的骨架

  1. 這是一個很好的手指運動，因為根音一直在跳五度。
  2. 右手：可以只彈簡單的柱式和弦 (Blocked Chords)。
  3. 左手根音：
    • A (Am)
    • D (Dm) -> 往下跳
    • G (G) -> 往上跳
    • C (C) -> 往下跳
    • F (F) -> 往上跳
    • B (Bdim) -> 往下跳
    • E (E7) -> 往上跳
    • A (Am)
  4. 挑戰：保持速度穩定！這就是五度圈的律動。

任務二：即興模進

  1. 右手想一個簡單的短句（例如 3個音：Mi-Re-Do）。
  2. 配上 C 和弦。
  3. 現在把和弦換成 Am。
  4. 右手把短句移位（例如：Do-Si-La）。
  5. 這就是作曲的第一步：Sequence the motif。
